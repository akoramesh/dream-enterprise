# Dream Enterprise – Professional Website

An advanced, responsive multi-page website for a professional consulting firm.

## What’s Included

- **Left hamburger menu** – Opens a full left-side drawer listing all pages (Home, About, Services, Shop, Reviews, AI Tools, Contact). Works on tablet and mobile (≤900px). Overlay + close button included.
- **AI Tools page** – Interactive AI Business Strategy Advisor: pick industry, goal, market, and stage to get tailored recommendations (frontend demo).
- **Shop page** – Digital products & kits with ratings; recommendations linked from Home and Reviews.
- **National & International reviews** – Dedicated page + homepage section.
- **Modern design** – Navy + gold palette, Inter font, sticky header, responsive layout.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home – hero, services, about preview, reviews, shop recommendations |
| `about.html` | Story, values, team |
| `services.html` | Service offerings + process |
| `shop.html` | Digital products recommended by partners |
| `reviews.html` | Collaborator reviews + product recommendations |
| `ai-tools.html` | **AI Strategy Advisor** interactive tool |
| `contact.html` | Contact form |

## How to use

1. Open the `dream-enterprise-pro` folder.
2. Open `index.html` in any modern browser.
3. Resize the window below ~900px width to see the left hamburger menu.
4. Click ☰ to open the drawer with all portal links.

## Notes

- Mobile/tablet: hamburger is on the **left**; menu slides in from the left.
- Desktop: full horizontal nav with all links.
- Contact form and shop CTAs are front-end demos.
- AI Advisor is a client-side demo (no external API required).
- Customize colors via CSS variables at the top of `styles.css`.
